# Guide — Biométrie

**Accès** : menu **Modules → Biométrie**.

## Empreintes des voyageurs

1. Rechercher le dossier du voyageur.
2. **Capturer** les doigts un à un (numérotation 1..5 main gauche, 6..10 main droite) ; la
   qualité est contrôlée à la capture.
3. **Contrôle de doublon** : avant enregistrement, l'application compare l'empreinte au
   registre et signale une correspondance éventuelle (même personne déjà enregistrée).
4. **Enregistrer** : images et gabarits sont conservés avec la personne.

## Opérateurs

- **Enrôlement** : deux doigts par opérateur (premier et second), depuis l'écran Biométrie →
  Opérateurs ou Administration → Utilisateurs.
- **Connexion par empreinte** : depuis l'écran de connexion (bouton **Empreinte**). Un
  compte sans empreinte enrôlée ne peut pas utiliser ce mode.

## Remarques

- Les périphériques sont simulés dans la livraison de démonstration : les images produites
  sont synthétiques. Le branchement du matériel réel se fait derrière les mêmes interfaces,
  sans modification des écrans.
- Vérifier la propreté du capteur et la qualité affichée avant de valider une capture.
