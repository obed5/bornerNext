# Guide — Listes de surveillance et personnes douteuses

**Accès** : menu **Modules → Surveillance**.

## Listes de surveillance

1. **Ajouter une entrée** : type (personne ou document), nom et prénom (et variantes de
   translittération), date de naissance, sexe, nationalité, numéro de document, source,
   document de référence, information utile, photo, action à mener.
2. **Annuler une entrée** : date d'annulation, source d'annulation et document de référence
   — l'entrée reste consultable.
3. **Autoriser** une personne inscrite (dérogation) : l'application cesse alors d'alerter
   pour cette personne, la décision est tracée.
4. **Empreintes de liste** : associer une empreinte à une entrée pour la correspondance
   biométrique.

## Comment fonctionne l'alerte

- À l'enregistrement d'un passage, la personne et le document sont comparés aux listes selon
  plusieurs critères (nom exact ou très proche, date de naissance, nationalité, numéro de
  document, année de naissance proche, inversion nom/prénom, variantes de translittération).
- Une correspondance déclenche l'**inscription en seconde inspection** et une marque sur le
  mouvement ; la fiche du mouvement indique la liste d'origine.

## File de seconde inspection (dossiers douteux)

1. **À traiter** : dossiers envoyés par les agents (motif de contrôle, note de l'inspecteur).
2. **Décision du superviseur** : action à mener (autoriser, refuser, retenir, transmettre),
   note du superviseur ; en cas de refus, la justification et l'officier sont consignés.
3. Le dossier passe ensuite **traité** (ou **clos**) : la file se vide au fur et à mesure.
4. **Contrôle inverse** : à partir d'une entrée de liste, rechercher les passages
   correspondants dans le registre local (personnes déjà passées).

## Remarques

- Chaque décision est nominative, horodatée et auditée.
- Ne jamais annuler une entrée pour « faire passer » un voyageur : l'annulation est motivée
  et tracée.
