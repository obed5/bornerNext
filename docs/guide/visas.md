# Guide — Visas

**Accès** : menu **Modules → Visas**.

## Délivrer un visa

1. **Rechercher le document** du demandeur (le visa est rattaché à un document).
2. Renseigner : type de visa, entrées (unique/multiple), période, dates de délivrance et
   d'expiration, durée autorisée, numéro, référence et numéro de reçu, adresse et contact,
   employeur ou personne invitante, province de destination.
3. **Enfants rattachés** : ajouter les enfants bénéficiaires (nom, prénom, naissance).
4. **Enregistrer** : le numéro de visa est conservé tel que saisi (numérotation du poste).

## Suivi

- **Recherche** : par numéro de visa, nom ou document.
- **Révocation** : un visa peut être révoqué (date et motif audités) ; il reste consultable.
- Les visas délivrés apparaissent dans les éditions (fiche visa, statistiques) et dans les
  contrôles d'admission : à l'enregistrement d'un mouvement, la validité du visa présenté
  est vérifiée.
