# Guide — Éditions et rapports

**Accès** : menu **Modules → Éditions et rapports**.

## Produire une édition

1. Choisir l'édition dans le **catalogue** (8 familles) :
   - **Impressions individuelles** : fiche d'enregistrement du passage, visa, permis,
     refus d'entrée, amende, ordre de reconduite, antécédents médicaux, fiche sanitaire vierge ;
   - **Mouvements** : synthèse, par poste frontière, journalière/hebdomadaire/mensuelle,
     registre détaillé des passages, enfants rattachés, statistiques par vol ;
   - **Secondes inspections**, **Nationalités**, **Profils et permis**, **Transport**,
     **Échanges**, **Santé**.
2. Renseigner les **critères** proposés (période, poste, sens, pays, type de document, visa,
   vol, inspecteur, état civil) — seuls les critères utiles à l'édition sont affichés.
3. **Aperçu** affiche à l'écran les tableaux et la synthèse (totaux et taux).
4. **Exporter en PDF** (choisir l'emplacement) ou **Imprimer**.

## Bonnes pratiques

- Les fiches individuelles se lancent aussi depuis les écrans métier (impression contextuelle
  du dossier, du permis, du refus, de la fiche sanitaire).
- Une édition de registre est plafonnée en nombre de lignes ; restreindre la période pour un
  document complet.
- Les impressions et exports sont journalisés dans l'audit.
- Le premier aperçu d'une édition après un import massif peut être lent : voir le manuel
  d'exploitation (statistiques).
