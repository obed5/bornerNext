# Guide — Fiche sanitaire du voyageur

**Accès** : menu **Modules → Fiche sanitaire**, ou bouton depuis un dossier (Enregistrement
passeport).

## Établir une fiche

1. **Rechercher le dossier** du voyageur (numéro de document).
2. **Appliquer** le questionnaire : la fiche est créée avec sa durée de validité.
   Une seule fiche active par questionnaire et par dossier : une nouvelle application
   n'est possible qu'après expiration ou clôture.
3. **Répondre aux questions** : listes de choix, dates, textes libres ; certaines questions
   n'apparaissent qu'en fonction des réponses précédentes (questions de suivi).
4. **Enregistrer les réponses** (à tout moment).
5. **Valider la fiche** : l'application contrôle que toutes les questions requises sont
   renseignées, puis affiche la **conclusion** (message de fin) :
   - libre pratique,
   - orientation vers le service médical,
   - surveillance sanitaire.

## Imprimer

- **Imprimer la fiche vierge** : pour la remettre au voyageur ou la remplir à la main.
- La fiche complétée est consultable dans les éditions de la famille Santé.

## Remarques

- La conclusion est déterministe : elle suit la première règle satisfaite dans l'ordre des
  réponses enregistrées — les réponses doivent donc être enregistrées avant validation.
- Une fiche expirée est signalée ; appliquer un nouveau questionnaire pour la période en cours.
